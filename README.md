# SleepAI Lab — EEG 기반 수면 분석 & 수면 장애 조기 스크리닝 프로토타입

> ⚠️ **중요**: 본 프로젝트는 실제 의료 진단을 대체하지 않는 **AI 기반 수면 분석 및 조기 스크리닝 프로토타입**입니다.
> 모든 데이터는 발표 시연을 위한 **샘플(시뮬레이션) 데이터**이며, 실제 EEG 센서·딥러닝 추론을 수행하지 않습니다.

## 1. 프로젝트 개요
- **목표**: EEG/PSG 신호를 기반으로 수면 단계를 자동 분류하고, 수면 질을 정량 평가하며, 수면 장애 의심 패턴을 조기에 스크리닝하여 개인 맞춤형 개선 가이드를 제공
- **구성물**
  1. `presentation.html` — 발표용 PPT (reveal.js 기반, 브라우저에서 바로 시연 가능)
  2. `index.html` + `css/`, `js/` — 실제 클릭 시연 가능한 웹 서비스 프로토타입 (Demo Mode)

## 2. 완료된 기능

### 발표용 PPT (`presentation.html`)
- reveal.js 기반 슬라이드 (방향키 또는 화면 하단 화살표로 이동)
- 세로 중첩(vertical stack) 구조: Cover를 제외한 6개 섹션(01~06)이 각각 하나의 최상위 슬라이드 그룹이며, 그 안에 소제목 슬라이드 아래로 콘텐츠 슬라이드들이 세로로 중첩되어 있습니다. **오른쪽 화살표(→)**로 다음 섹션(소제목)으로 이동하고, 각 섹션 안에서는 **아래쪽 화살표(↓)**를 눌러 ①→②→③ 순서로 콘텐츠 슬라이드를 넘겨봅니다.
- 구성: Cover → 01 배경/문제정의(소제목+콘텐츠 3장) → 02 프로젝트 목표(소제목+콘텐츠 1장) → 03 시스템 구성(소제목+콘텐츠 2장) → 04 데이터/AI 모델(소제목+콘텐츠 3장) → 05 서비스 화면·사용자 흐름(소제목+콘텐츠 8장, 실제 웹앱 스크린샷 포함) → 06 기대효과·향후 발전방향(소제목+콘텐츠 2장 + Closing)
- 실제 프로토타입 화면 캡처 이미지(`images/screen-*.png`)를 삽입해 서비스 동작을 시각적으로 설명

### 웹 서비스 프로토타입 (`index.html`)
| 화면 | 주요 기능 |
|---|---|
| 메인 대시보드 | 수면 질 점수, 총 수면시간, 수면효율, 각성횟수, 입면시간, 수면단계 비율 도넛차트, 최근 7일 추이 |
| EEG/PSG 데이터 분석 | 샘플 레코드 3종 선택(Demo Mode), 파일 업로드 UI(시연용), 7단계 분석 진행 애니메이션, EEG 원시파형/FFT 대역파워/Wavelet 시간-주파수 히트맵 시각화 |
| 수면 단계 분석 | Wake/REM/N1/N2/N3 Hypnogram(계단형 그래프), 단계별 비율·시간·정상범위 비교 카드 |
| 수면 질 리포트 | 종합 점수, 수면효율·총수면시간·입면시간·중간각성·REM/NREM비율·N3비율 카드, 정상범위 비교 막대그래프 |
| 수면 장애 스크리닝 | 무호흡 의심/잦은 각성/수면구조 이상/불규칙 패턴을 "주의필요·관찰권장·양호"로 표시(진단 아님), 전문 상담 권고 문구 포함 |
| 맞춤형 수면 가이드 | 취침·기상시간, 수면환경, 카페인/전자기기, 수면습관 개선 제안 + "오늘 밤 실천" 팁 3가지 |
| 반응형 UI | 데스크톱 사이드바 / 모바일 햄버거 메뉴 전환, 모든 카드·차트 반응형 배치 |

### Demo Mode 샘플 데이터 (`js/data.js`)
- Sleep-EDF Expanded / SHHS 데이터셋의 구조(채널명, 샘플링레이트, Epoch 30초 단위 등)를 참고해 시드 기반 난수로 생성한 3가지 샘플 레코드
  1. **SC4001E0** — 건강 성인 정상 수면 패턴
  2. **ST7022J0** — 수면호흡 이상 의심(잦은 각성) 패턴
  3. **SC4092G0** — 불규칙 수면 패턴(교대근무 가정)
- 각 샘플은 AASM 표준에 준하는 정상 참고범위와 비교해 수면 질 점수, FFT 밴드파워, 스크리닝 결과, 맞춤 가이드를 현실적인 범위 내에서 산출
- "데이터 → AI 분석(7단계 진행 애니메이션) → 수면단계 분류 → 수면질 평가 → 스크리닝 → 맞춤 가이드" 순서로 결과 표시

## 3. 사용자 흐름
```
메인 대시보드(비어있음)
   └─▶ [EEG/PSG 데이터 분석] 샘플 선택 → AI 분석 시작 → 진행 애니메이션
         └─▶ EEG 파형/FFT/Wavelet 결과 확인
               └─▶ 수면 단계 분석(Hypnogram)
                     └─▶ 수면 질 리포트
                           └─▶ 수면 장애 스크리닝
                                 └─▶ 맞춤형 수면 가이드
                                       └─▶ 대시보드로 복귀 (분석 결과 반영됨)
```
- 분석 전 사이드바에서 다른 화면(단계분석/리포트/스크리닝/가이드)에 진입 시 "먼저 EEG 분석이 필요합니다" 안내 화면(Gate)으로 유도됩니다.

## 4. 파일/경로 구조
```
index.html                  메인 웹앱 (7개 화면 SPA 구조)
presentation.html           발표용 PPT (reveal.js)
css/style.css                웹앱 스타일
css/presentation.css         PPT 스타일
js/data.js                   샘플 데이터 생성 + 분석 엔진(시드 기반 시뮬레이션)
js/app.js                    화면 전환, Chart.js 렌더링, 데모 분석 진행 로직
images/screen-*.png          PPT에 삽입된 웹앱 스크린샷
```
현재 프로젝트는 별도의 서버 API나 테이블(Table API)을 사용하지 않으며, 모든 데이터는 브라우저 내 JavaScript(`js/data.js`)에서 시드 기반으로 즉시 생성·계산됩니다. (새로고침 시 동일한 시드로 동일한 결과 재현)

## 5. 기술 스택
- HTML5 / CSS3 / Vanilla JavaScript (프레임워크 없음)
- Chart.js 4 (파형, FFT, Hypnogram, 도넛/라인/막대 차트)
- reveal.js 4.6 (발표용 프레젠테이션)
- Font Awesome 6 (아이콘), Google Fonts – Noto Sans KR

## 6. 아직 구현되지 않은 기능 / 한계
- 실제 EEG 파일(.edf 등) 업로드 시 실제 파싱·분석은 수행하지 않음 (UI만 제공, 항상 샘플 데이터로 데모 진행)
- 실제 CNN/RNN 딥러닝 모델 추론 없음 — 모든 분석 결과는 통계적 규칙과 시드 난수로 산출한 시뮬레이션 값
- 사용자 계정/로그인, 다중 사용자 데이터 저장 기능 없음
- 서버 DB(Table API) 연동 없음 — 새로고침 시 이전 분석 세션은 초기화됨

## 7. 향후 개발 제안
1. 실제 EEG 파일(.edf/.csv) 파싱 라이브러리를 연동해 진짜 업로드 분석 지원
2. 실제 학습된 CNN/RNN(또는 Transformer) 모델을 백엔드/엣지에서 추론하도록 확장 (현재는 정적 사이트 한계로 불가 — 별도 백엔드 필요)
3. Table API 또는 별도 DB로 사용자별 수면 기록을 누적 저장해 장기 트렌드 분석 제공
4. 실제 웨어러블/EEG 밴드 연동을 통한 실시간 데이터 수집
5. 의료기관 연계 상담 예약 등 후속 조치 플로우 추가

## 8. 배포
현재 이 프로젝트는 정적 파일로 구성되어 있어 **Publish 탭**에서 바로 배포할 수 있습니다.
배포 후에는 `index.html`(웹 서비스)과 `presentation.html`(발표 PPT) 두 URL을 각각 공유하여 시연할 수 있습니다.
