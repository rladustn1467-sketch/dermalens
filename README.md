# 더마렌즈 (DermaLens)

**AI 기반 안면 피부질환 분석 서비스 — 웹앱 프로토타입**

Python · PyTorch와 DenseNet121 기반 이미지 분류 모델로 구현하는 안면 피부질환 진단 보조 웹앱입니다.
안면부 이미지를 업로드하거나 카메라로 촬영하면 **6가지 분류(건선 · 아토피 · 여드름 · 주사 · 지루 · 정상)** 에 대한
예측 확률을 확인하고, 클래스 정보와 주의사항을 함께 살펴본 뒤 분석 기록으로 저장할 수 있습니다.

> ⚠️ **의료정보 안내** — 본 서비스는 의학적 진단이 아닌 **진단 보조 수단**이며 분석 결과는 참고용입니다.
> 정확한 진단과 치료는 반드시 피부과 전문의와 상담하세요.
>
> 🔬 **프로토타입 안내** — 현재 웹앱의 분석 결과는 실제 모델 추론이 아닌 **프로토타입(mock)** 입니다.
> 실제 모델 서빙 연동은 향후 확장 예정 항목입니다.

## 1. 프로젝트 목표

원본 프로젝트 개요(웹앱·PPT 기획자료)를 기준으로 정리했습니다.

| 구분 | 내용 |
| --- | --- |
| **진단 보조 도구** | 병변 이미지를 분석해 6가지 안면부 병변 유형을 분류하고 진단·치료 결정을 보조 |
| **원격 진료 적용** | 모바일로 업로드된 안면부 이미지를 분석하고 전문의 상담 여부를 안내 *(향후)* |
| **연구·데이터 분석** | 학습된 모델을 환자의 피부과 진료 지원과 연구·데이터 분석에 활용 |
| **개인화 서비스** | 학습된 모델을 활용한 모바일앱 제작 및 개인화 서비스 추진 *(향후)* |

**프로젝트 결과물:** 건선 · 아토피 · 여드름 · 주사 · 지루 · 정상 **6개 Class를 인식하는 피부질환 감지 모델**,
스마트폰 카메라를 통한 피부 상태 평가, HTML · CSS · JS 기반 WebApp,
그리고 습진 · 백반증 등 **추가 질환 모델 개발 로드맵**.

**기술 스택:** DenseNet121 · aihub.or.kr DataSet · Python · PyTorch · WebApp(HTML, CSS, JS)

## 2. 현재 구현된 기능

### 화면 · 사용자 흐름
- **홈** — 히어로(서비스 소개·CTA), 4단계 분석 흐름, 6가지 분류, 주의사항
- **피부 분석** — 이미지 업로드(드래그 앤 드롭) / 카메라 촬영(안면 가이드 오버레이) 두 가지 입력 방식
- **AI 분석 진행** — 원형 진행률 + 수평 진행바 + 4단계(전처리·특징 추출·클래스 분류·결과 정리) 시각화
- **분석 결과** — 상위 예측과 신뢰도, 6가지 분류별 확률 바, 분석 조건(모델·이미지 품질·해상도),
  클래스 정보 · 결과 해석 안내 · 주의사항(접이식), 인쇄/PDF 저장
- **질환 정보(클래스 정보)** — 6가지 분류 카드 + 상세 페이지(설명·태그·해당 분류 분석 기록)
- **분석 기록** — 저장된 분석 기록 목록, 요약 통계, 결과 다시 보기, 삭제
- **프로젝트 소개** (상단 내비게이션·모바일 탭바에서 제외, **푸터의 '프로젝트 소개' 링크로만 접근**) — 서비스 목적·화면 흐름, 이 프로젝트가 하는 일,
  왜 필요한가, 프로젝트 결과물, AI 모델 및 기술 구성, 현재/향후 구현 범위, 확장 로드맵, 의료정보·프로토타입 안내

### 데이터 · 편의 기능
- 이미지 업로드 시 **브라우저 안에서만** 처리 (서버로 원본 이미지 전송 없음)
- 분석 완료 시 썸네일과 함께 **분석 기록 자동 저장** (RESTful Table API)
- 결과 화면 **메모 저장** 기능
- 반응형 레이아웃 (데스크톱 · 태블릿 · 모바일 하단 탭바)
- 접근성: 시맨틱 마크업, ARIA 속성, 키보드 조작, `prefers-reduced-motion` 대응

## 3. 기능 진입 URI (해시 라우팅)

단일 페이지 앱(SPA)이며 모든 화면은 `index.html` 위에서 해시로 전환됩니다.

| 경로 | 화면 | 설명 |
| --- | --- | --- |
| `#/` | 홈 | 서비스 소개 및 전체 개요 |
| `#/analyze` | 피부 분석 | 이미지 업로드 / 카메라 촬영 |
| `#/about` | 프로젝트 소개 | 상단 내비게이션·탭바에는 노출하지 않고 **푸터의 '프로젝트 소개' 링크로만** 접근 |
| `#/result` | 분석 결과 | 분석 완료 후 표시 (분석 실행 시 자동 전환) |
| `#/diseases` | 질환 정보(클래스 정보) | 6가지 분류 목록 |
| `#/diseases/{id}` | 클래스 상세 | `id`: `psoriasis` · `atopic` · `acne` · `rosacea` · `seborrheic` · `normal` |
| `#/history` | 분석 기록 | 저장된 분석 기록 목록 |
| `#/about` | 프로젝트 소개 | 목표 · 결과물 · 기술 구성 · 구현 범위 |

### 사용하는 REST API 엔드포인트

| 메서드 | 경로 | 용도 |
| --- | --- | --- |
| `GET` | `tables/analysis_history?limit=100&sort=analyzed_at` | 분석 기록 목록 조회 |
| `POST` | `tables/analysis_history` | 분석 결과 저장 |
| `PATCH` | `tables/analysis_history/{id}` | 메모 수정 |
| `DELETE` | `tables/analysis_history/{id}` | 기록 삭제 |

## 4. 데이터 모델

### 테이블: `analysis_history`

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| `id` | text | 레코드 고유 ID (시스템 관리) |
| `analyzed_at` | number | 분석 시각 (Unix ms) |
| `disease_id` | text | 상위 예측 클래스 ID (`psoriasis` \| `atopic` \| `acne` \| `rosacea` \| `seborrheic` \| `normal`) |
| `disease_ko` | text | 상위 예측 클래스 한글명 |
| `disease_en` | text | 상위 예측 클래스 영문명 |
| `confidence` | number | 상위 예측 확률 (%) |
| `quality` | number | 이미지 품질 점수 (0–100) |
| `probs` | text | 클래스별 확률 JSON 문자열 |
| `thumb` | text | 분석 이미지 썸네일 (data URL) |
| `model` | text | 사용된 모델 라벨 |
| `note` | text | 사용자 메모 |

- 저장소: **RESTful Table API** (`tables/analysis_history`)
- 저장 실패 시 **브라우저 localStorage**(`dermascan.history.v1`)에 대체 저장되며, 목록 조회 시 두 저장소를 병합합니다.

## 6. 아직 구현되지 않은 기능 (향후 확장 예정)

기획 자료·원본 프로젝트 개요에 **예정**으로 명시된 항목이며, 현재 서비스의 확정 기능이 아닙니다.

- **실제 모델 추론 연동** — 현재의 프로토타입 분석 결과를 실제 DenseNet121 모델 서빙으로 교체
- **심각도 평가** — 병변 유형과 함께 심각도를 평가
- **전문의 상담 여부 안내** — 분석 결과를 바탕으로 상담 필요성 안내
- **모바일앱 제작 · 개인화 서비스** — 학습된 모델을 활용한 앱 확장
- **추가 질환 모델 개발** — 습진(Eczema), 백반증(Vitiligo) 등
- **모델 고도화** — 하이퍼파라미터 튜닝 · 앙상블 기법 · 모바일 환경 경량화 최적화
- **사용자 인증 · 개인 계정** — 현재는 인증 없는 단일 사용자 환경

## 7. 개발 참고 및 다음 단계 제안

1. **실제 모델 서빙 연동** — 모델 추론 API(권한 불필요·CORS 허용)를 준비한 뒤 `js/app.js`의
   프로토타입 분석 함수(`runAnalysis` / `finishAnalysis`)를 실제 추론 호출로 교체합니다.
   *참고: 정적 웹사이트만으로는 모델 추론을 직접 수행할 수 없으므로 별도의 추론 서버가 필요합니다.*
2. **심각도 평가 · 상담 안내** — 결과 화면에 심각도 지표와 상담 권고 로직을 추가합니다.
3. **분류 클래스 콘텐츠 보완** — 각 클래스의 사진 예시·증상·진료 안내를 의료 전문가 검수를 거쳐 보강합니다.
4. **분석 기록 비교 기능** — 이전 분석과 현재 분석의 클래스별 확률 변화를 시각화합니다.
5. **접근성 · 다국어** — 한국어/영어 전환, 스크린리더 검증 강화.

### 참고한 기획 자료
- 프로젝트 개요: *Python을 활용한 안면 피부질환 진단 모바일앱 제작* (원본 프로젝트 내용)
- 기획 발표자료: `피부 .pptx` — 서비스 기능·화면 구성·사용자 흐름 파악용으로만 참고하고,
  웹앱의 UI/UX는 별도로 새롭게 구성했습니다.

## 8. 공개 URL

- **배포 방법**: **Publish 탭**에서 원클릭으로 배포할 수 있습니다.
- 배포 후 사이트가 제공되는 공개 URL은 Publish 탭에서 확인할 수 있습니다.
- 데이터 API는 사이트와 동일한 오리진의 상대 경로(`tables/analysis_history`)를 사용합니다.
