수면 부족과 수면장애는 만성질환, 인지기능 저하, 삶의 질 저하로 이어질 수 있어 조기 인식과 관리가 중요합니다.

기존 수면 측정 방식의 한계

웨어러블 기기

움직임(가속도) 기반 추정 → 실제 뇌파와 무관, 수면 단계 정확도에 한계

자가 설문 / 수면일기

주관적 인식에 의존 → 실제 수면 구조(N1~N3, REM)를 알 수 없음

병원 수면다원검사(PSG)

가장 정확하지만 高비용·예약 대기·1회성 검사로 일상적 추적 어려움

객관적 수면 단계 · 질 지표

EEG는 실제 뇌활동을 반영하는 가장 객관적인 수면 지표입니다. AI 분석을 결합하면 병원급 정밀도에 근접한 결과를 더 쉽고 빠르게 제공할 수 있습니다.

6단계 파이프라인을 통해 원시 EEG 신호가 사용자가 이해할 수 있는 수면 리포트로 변환됩니다.

단계별 상세 설명

1. 데이터 수집EEG/EOG/EMG 등 다채널 생체신호를 30초 단위 Epoch으로 기록 (Sleep-EDF/SHHS 표준 구조 참고)
2. 전처리노이즈 제거, 필터링(밴드패스), 아티팩트(잡파) 제거로 신호 품질 확보
3. 특징 추출FFT로 주파수 대역(Delta/Theta/Alpha/Beta/Gamma) 파워 산출, Wavelet으로 시간-주파수 변화 포착
4. AI 분석CNN으로 Epoch 단위 패턴 인식, RNN(LSTM)으로 수면 단계의 시계열적 흐름을 반영
5. 이상 패턴 분석각성 빈도, N1 비율, 수면 구조 붕괴 등 스크리닝 룰 기반 패턴 탐지
6. 리포트 생성수면 질 점수, Hypnogram, 스크리닝 결과, 맞춤형 가이드를 자동 생성

04 데이터 및 AI 모델

공개 데이터셋 활용

Sleep-EDF Expanded

PhysioNet 제공, EEG(Fpz-Cz, Pz-Oz)·EOG·EMG 채널의 야간 수면 기록 (100Hz)

SHHS (Sleep Heart Health Study)

대규모 코호트의 다채널 PSG 데이터, 호흡·산소포화도 등 추가 지표 포함

본 프로토타입 샘플 데이터

위 데이터셋 구조를 참고해 생성한 시뮬레이션 데이터로 Demo Mode 제공

EEG 신호 전처리 & 특징 추출

  • 대역 필터링(0.3~35Hz)으로 기저선 잡파 및 고주파 노이즈 제거
  • 30초 Epoch 단위 세그멘테이션 (AASM 표준)
  • FFT 기반 주파수 대역별 파워 스펙트럼 산출 (Delta~Gamma)
  • Wavelet Transform으로 시간에 따른 주파수 변화(시간-주파수 지도) 생성

① 메인 대시보드

  • 수면 질 점수 · 등급을 한눈에 확인
  • 총 수면시간 / 수면효율 / 각성횟수 / 입면시간 카드
  • 수면 단계 비율 도넛차트, 최근 7일 추이 그래프

② EEG/PSG 데이터 분석 & Demo Mode

  • Sleep-EDF/SHHS 구조를 참고한 샘플 레코드 3종 중 선택
  • 실제 파일 업로드 UI + 분석 진행 상태 애니메이션
  • EEG 원시 파형 · FFT 주파수 대역 · Wavelet 시간-주파수 히트맵 시각화

③ 수면 단계 분석 (Hypnogram)

  • Wake/REM/N1/N2/N3 시간대별 변화를 계단식 그래프로 표현
  • 단계별 카드에서 비율·시간·정상 참고범위 비교(초과/미달/정상)

④ 수면 질 리포트

  • 종합 점수, 수면효율, 총 수면시간, 입면시간, 각성횟수 등 카드형 요약
  • 나의 수면 단계 비율 vs 정상 참고범위 비교 그래프

⑤ 수면 장애 스크리닝

  • 무호흡 의심 · 잦은 각성 · 수면구조 이상 · 불규칙 패턴을 "주의필요/관찰권장/양호"로 표시
  • "진단"이 아닌 "스크리닝"임을 명시, 전문 상담 권고 문구 포함

⑥ 개인 맞춤형 수면 가이드

  • 취침/기상시간, 수면환경, 카페인/전자기기, 수면습관 개선 제안
  • "오늘 밤 바로 실천" 카드로 즉시 실행 가능한 팁 3가지 제공

모바일 반응형 화면

  • 사이드바 → 상단 햄버거 메뉴로 전환
  • 모든 카드·그래프가 모바일 폭에 맞게 재배치

06 기대효과 및 향후 발전 방향

기대 효과

접근성 높은 상시 모니터링

병원 방문 없이도 일상적으로 수면 상태를 추적하고 이해할 수 있음

수면 장애 조기 인지

이상 패턴을 조기에 스크리닝하여 전문 진료 연계 시점을 앞당김

데이터 기반 습관 개선

개인 맞춤형 가이드를 통한 지속적인 수면 습관 개선 유도

향후 발전 방향

  • 실제 웨어러블/EEG 밴드 연동실시간 센서 데이터 수집 및 자동 분석 파이프라인 구축
  • 모델 정교화대규모 임상 데이터 학습, Transformer 기반 시계열 모델 도입 검토
  • 의료기관 연계 체계스크리닝 결과를 기반으로 한 전문의 상담·후속 검사 연계 서비스
  • 장기 트렌드 분석개인별 장기 수면 데이터 축적을 통한 생활습관·건강 상관 분석
